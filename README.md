О проекте

Products Store — учебный проект по тестированию интернет-магазина. Приложение позволяет просматривать каталог товаров, искать и фильтровать товары, изучать информацию о товарах, добавлять товары в корзину и оформлять заказ.

Что тестировалось
- Отображение каталога и карточек товаров.
- Поиск товаров и фильтрация.
- Просмотр информации о товаре.
- Добавление и удаление товаров из корзины.
- Проверка оформления заказа.
- Адаптивность интерфейса на мобильных устройствах.
- Кроссбраузерная совместимость.
- Проверка локализации интерфейса на русском и английском языках.
- Выявленные дефекты задокументированы в баг-репортах.
